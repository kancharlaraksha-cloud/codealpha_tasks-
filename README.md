# CodeAlpha Docker Web Server

## 📌 Project Overview

This project was developed as part of the **CodeAlpha DevOps Internship**.

The objective is to containerize and deploy a web server using Docker. The project demonstrates Docker image creation, container deployment, port mapping, container lifecycle management, and health monitoring.

## 🛠️ Technologies Used

- Docker
- Docker Desktop
- Nginx
- HTML
- PowerShell
- WSL2
